# Security Policy

## Supported versions

Security fixes are applied to the latest published release of `binary-sentinel` on npm / GitHub Packages.

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

Report privately via GitHub Security Advisories for this repository:

https://github.com/MrLouisWright/binary-sentinel/security/advisories/new

Include:

- Affected package version(s)
- Impact and attack scenario
- Steps to reproduce or a proof of concept if you have one

You should receive an acknowledgement within a few days. Please give us a reasonable window to publish a fix before any public disclosure.

## Non-security bugs

Ordinary bugs and feature requests belong in [GitHub Issues](https://github.com/MrLouisWright/binary-sentinel/issues).
